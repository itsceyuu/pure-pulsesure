# Rencana Scene

Urutan awal scene untuk video explainer PURE. Durasi, transisi, dan copy final akan ditetapkan setelah storyboard serta voice-over disetujui.

1. **HookScene** — Membuka dengan visual PPG dan pertanyaan singkat tentang apakah sebuah angka BPM selalu dapat dipercaya.
2. **ProblemScene** — Menunjukkan noise, artefak gerakan, dan risiko menampilkan hasil saat kualitas sinyal buruk.
3. **UserContextScene** — Memperlihatkan konteks pemakaian wearable dan kondisi pengguna yang memengaruhi pembacaan.
4. **SolutionScene** — Memperkenalkan PURE sebagai pendekatan untuk menilai kualitas dan reliabilitas sebelum menyajikan hasil.
5. **AiWorkflowScene** — Menjelaskan alur input PPG, deteksi artefak, model AI, quality score, dan keputusan keluaran.
6. **DashboardDemoScene** — Mendemokan state dashboard, penampilan atau penahanan BPM, serta corrective guidance.
7. **ArchitectureScene** — Merangkum alur hardware, pemrosesan, model, dan dashboard dalam diagram sistem.
8. **ClosingScene** — Menutup dengan manfaat utama, pesan kehati-hatian, logo PURE, dan call to action yang disetujui.

Dokumen ini hanya rencana struktur. Implementasi React/TypeScript belum dibuat.
